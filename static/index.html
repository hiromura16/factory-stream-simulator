イベント送信シミュレーター

設備・センサー・工程イベントを生成し、MQTTブローカーへ送信するシミュレーターです。Kafka、NATS、IoT基盤、ストリーム処理、リアルタイム分析の検証にも利用できます。

接続中
ヘルプ・設定・API
入力項目の説明

項目にマウスを重ねると、その場で説明を表示します。? にキーボードで移動しても読めます。

設定値はプレビューで確認してから実行できます。

用語集

イベントを送る

イベントを選ぶ → 接続と送信条件 → 確認 → 送信

イベントのひな型を選ぶ

選択すると合成イベントの設定を読み込みます。接続先は維持し、まだ送信しません。

保存済みプリセットから始める

送信内容を確認

メッセージ本文、トピック、サイズを送信前に確認できます。
