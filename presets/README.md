## ひな型ごとの内容

### 01-quickstart

**小さく試す** · [JSONをダウンロード](01-quickstart.json)

- **想定する状況**　設備イベントやMES・ERPの連携イベントを受信側へ継続配送する想定です。
- **このプリセットの内容**　同じ汎用項目を使用し、件数・速度・バッチを段階的に変更する負荷試験。大規模試験前に少量で接続先の性能と容量を確認します。 件数30、目標速度10件/秒（0は制限なし）。
- **確認すること**　実測レート、event_timeと受信時刻、record_keyによる重複排除、outboxの配送状態。
- **実行前の条件**　使用するブローカー/APIを接続先から選択してください。HTTP形式の設定はHTTP接続時に適用。キャプチャは外部へ送信しません。 設定は自由に変更して別名保存できます。
